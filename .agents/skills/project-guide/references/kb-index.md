## Sources Added During Development

Resolve exact build and verification commands from the actual build configuration and project instructions once configured. Do not treat proposed commands as working setup instructions.

Add concrete source entries here when meaningful documents become available. Do not create placeholder documents or duplicate their contents.

## Missing or Conflicting Information

Name the missing requirement, command, or decision and explain which conclusion depends on it. Refer the unresolved point to the project lead rather than inventing project behavior.
